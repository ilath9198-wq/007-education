## 1. Project Overview

**EDVANCE** is an industry-specific digital demonstration platform built to showcase what modern educational institutions (colleges, competitive coaching centres, skill academies, IT training institutes, and tuition centres) need in a digital presence.

The platform provides a complete institutional experience:
- 11 dedicated, cleanly structured pages and routes.
- **Strictly ZERO `.html` extensions** anywhere in URLs or file architecture.
- Atmospheric, authentic educational photographic hero backgrounds on every route.
- Deep navy/royal gradient scrims with crisp drop-shadowed white typography.
- Solid, high-contrast, prominent CTA buttons with zero transparency issues.
- A distinctive **Interactive Learning Index Navigation** that unfolds vertically like an academic course syllabus.

---

## 2. Dedicated Pages & Routes

1. **Home (`/`)**: Institutional hero, 4-pillar advantage, popular courses, campus facilities preview, student testimonials, and admissions banner.
2. **About Us (`/about`)**: Heritage story, vision & mission, 4 core values, 4-stage cognitive mastery pedagogy, and governing leadership.
3. **Academics (`/academics`)**: 6 specialized academic streams with eligibility, durations, core curricular highlights, progression paths, and demonstration disclaimer.
4. **Courses (`/courses`)**: 12-course catalogue with live keyword search, 7 category filter pills, and interactive course detail modal showing full modular syllabi.
5. **Admissions (`/admissions`)**: 4-step admission roadmap, deadlines calendar table, on-page admission application form with code generator (`EDV-ADM-2026-XXXX`), and FAQ accordion.
6. **Faculty (`/faculty`)**: 6 detailed faculty profiles with department filter bar, research bios, expertise tags, and mentorship booking triggers.
7. **Campus & Facilities (`/campus`)**: 6 campus infrastructure pillars, safety/HEPA filtration specifications, and campus tour booking.
8. **Student Life (`/student-life`)**: 6 student clubs & guilds, annual milestone events calendar, and psychological wellness support.
9. **Results & Achievements (`/results`)**: Academic performance cards, competitive exam rankings (JEE, NEET, GATE, UPSC), placement metrics ($42k highest package), and ranker quotes.
10. **Resources (`/resources`)**: 8 downloadable study notes, sample examination papers, handbooks, live search, and simulated download triggers.
11. **Contact Us (`/contact`)**: Campus location address, direct phone/email channels, operating hours, interactive inquiry form with ticket generator (`EDV-ENQ-2026-XXXX`), and WhatsApp counselor link.

## 3. Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS with custom institutional color scales (`navy-900`, `royal-600`, `amber-500`)
- **Icons:** Lucide React
- **Typography:** Inter (Sans-serif) & JetBrains Mono (Academic codes)
- **State Management:** React Context API (`EnrollmentContext`)

## 4. Local Development

To run the project locally:

```bash
# Clone the repository
git clone https://github.com/ilath9198-wq/007-education.git

# Navigate to project directory
cd 007-education

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 5. Production Build

To verify and create a production build:

```bash
npm run build
npm start
```
